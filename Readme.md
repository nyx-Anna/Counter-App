# Counter App
A simple and interactive Counter Application built using HTML, CSS, and JavaScript. This project demonstrates core JavaScript concepts like DOM manipulation, event handling, and basic logic building.

# Features
* Increase the counter
* Decrease the counter
* Reset the counter
* Keyboard support (Arrow keys & reset key)
* Dynamic color change based on value
* Clean and responsive UI

# Tech Stack
* HTML
* CSS
* JavaScript (Vanilla JS)

# How It Works
* Click *+* to increase the counter
* Click *-* to decrease the counter
* Click *Reset* to set counter to 0
* Use keyboard:
  * ⬆ Arrow Up → Increase
  * ⬇ Arrow Down → Decrease
  * *R* → Reset
